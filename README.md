# watskeburt

**watskeburt** is planned as a command-line tool to help you recall what you
worked on during the day, especially when writing timesheets or logging hours.

## Status

This project is at the planning stage. The CLI, its data sources, and setup
instructions have not been implemented yet.

## Plan

1. Define the first use case, including which activity sources to support and
   what a useful daily summary should contain.
2. Design a small CLI and decide how activity data is collected and handled
   with the user's privacy in mind.
3. Implement a focused first version, with tests for its core behavior.
4. Document installation, configuration, and usage once those features exist.
